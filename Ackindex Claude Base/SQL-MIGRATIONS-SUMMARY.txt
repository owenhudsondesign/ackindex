================================================================================
                      TROUBLESHOOTING
================================================================================

"pgvector extension is not installed"
  → Go to Supabase Dashboard → Database → Extensions
  → Search for "vector" and click "Enable"
  → Re-run supabase-migration-stage8.sql

"Column already exists"
  → Column already exists from previous run
  → This is OK, migration uses IF NOT EXISTS

"RLS policy errors"
  → Check that supabase-schema.sql ran successfully
  → Verify user is authenticated
  → Re-run supabase-schema.sql

Index timeout
  → Normal for large tables, let it run
  → For >100K chunks, consider HNSW index
